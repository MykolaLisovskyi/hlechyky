# Гончарне коло v7 — B1 «Жива хата»: як реалізовано

Контракт — `clicker-v7.md` §3 і §4 B1. Сервер не змінювався (лише читається вид). Файли:
`web/games/clicker-scene.js` / `.css` (нова частина), точкові правки в `clicker.js`, `clicker.css`,
`clicker-craft.js`, `clicker-craft.css`.

## Сцена 4:5 і шари

- `.clk-stage` — `aspect-ratio: 4/5`, до 520 px; ліва колонка на ПК — `minmax(300px, min(520px, 60%))`, права —
  щонайменше 250 px. Сцена — `container-type: inline-size`: сирці на полиці мають розмір у `cqw` і однакові на
  телефоні й на ПК.
- **viewBox хати й back-шару тепер 360×450** (було 360×396). Опорні точки — `api.scene` (їх виставляє частина scene):

  | що | де (у viewBox 360×450) |
  |---|---|
  | небо й світ за хатою | y 0…130; дорога — y 112; хвіртка — x 96…120, y 100…128 |
  | стріха | y 122…152 |
  | полиця з сирцями (DOM) | верх полиці y 176 (css `top: 39%`), x 25…335 |
  | коло | центр (180, 331), r 101; долівка — від y 372 |
  | вікно / ікона | x 226, y 190, 54×46 / x 292, y 188, 34×42 |
  | горно | x 282…352, y 272…380 (димар — x 341) |
  | вивіска драбини / знаряддя | x 6, y 186, 68×34 / x 4…94, y 226…336 |
  | лава (з собакою) / скриня | x 4…94, y 400 / x 292…352, y 402…444 |

  Малюнок частини в `api.layer(st, 'back', id)`, зроблений під старі 360×396 і «стоїть на підлозі», стане на місце
  з `transform="translate(0 54)"` на своєму `<g>`. DOM у front-шарі — у відсотках сцени: `x% = x/360·100`, `y% = y/450·100`.
- Позиції розписного глека (`golden.x/y`) і глека з полиці (`fall.x`) — у відсотках, як і були. Глек з полиці тепер
  стартує з полиці (`top: calc(39% − 64px)`), політ — до 92 % висоти сцени (`--clk-drop` рахується від `offsetTop`).

## Хата (clicker-scene.js)

- Малюнок збирається рядком з «підпису» стану: рівні драбини сходинками 1/25/50/100, підмайстри 1/10/25/50, піч,
  куплені знаряддя/прикраси, секрет `cat`, пора року, фаза місяця (16 кроків), погода. Підпис той самий — DOM не
  чіпаємо (вид летить щопачки кліків).
- Світ за хатою: пагорби з музеєм, школою й Цар-глеком (росте з віхами), річка з чайкою (CSS-рух), ярмаркові намети
  (1–3 + прапорці на 100), артіль-мазанки з димком, глинище (купи, драбина, журавель на 50), чумацький віз із волами
  (раз на ~75 с, обоз з 25, Чумацький Шлях уночі з 50), тин із глечиками, хвіртка, півень.
- Під стріхою: комин і димар горна з димом, каганець, вивіска з 8 гніздами-емблемами, 10 мальованих знарядь на
  кілочках, рушник над колом, вікно з калиною (те саме небо), ікона з лампадкою, горно з вогнем, жаринками й
  сяйвом від рівня, лава з собакою, мальована скриня, кіт на полиці (хвіст, кліпає, очі світяться вночі),
  підмайстри-люди: місить глину (1), носить кошик глини вздовж долівки (10), підкидає дрова (25), другий носій (50).
- **День і ніч за Києвом**: схід/захід від дня року (≈8 год у грудні, ≈16,4 год у червні, полудень ≈ 9:58 UTC),
  кольори неба/стін/землі — CSS-змінні `--clks-*` на сцені раз на 20 с; сонце й місяць ідуть дугою (transform);
  уночі — зорі, світло каганця/лампадки/горна, вікна в селі. Пора року — місяць за Києвом: соняхи / калина з
  листопадом / цвіт вишні / сніг на стрісі, тину й підвіконні.
- **Погода** — лише з `view.market.weather` ('sun' | 'rain' | 'frost' | 'cloud'): дощ, сніжинки, сірі хмари. Нема
  поля — без опадів. Сервер нічого не вигадує.
- Перевірка часу: `HClicker.sceneTime = '2026-12-20T22:00:00+02:00'` (або `?clkTime=…`).

## Відчуття

- Клік: глина пружинить (WAAPI на обгортці `.clk-squash`), руки гончаря біля кола (з'являються на 0,9 с після
  кліку й поки розгін > 25 %), бризки — краплі кольору глини з дугою падіння.
- Виріб готовий — більша пружина; розбитий глек з полиці — трус сцени 320 мс; розписний глек і `rare` — спалах.
- `prefers-reduced-motion`: без трусу, пружини й анімацій хати (віз, чайка стоять).
- Частинки: ядро вже тримає ≤ 48 на шар.

## Звук (Web Audio, синтез)

Типово вимкнений; кнопка в правому верхньому куті сцени, гучність — повзунок (на ПК при наведенні, на телефоні —
після першого торкання), пам'ять — `clk.sound`, `clk.vol`. AudioContext створюється лише після жесту
(`navigator.userActivation`). Гул кола — пилка крізь фільтр від розгону й пасиву, стихає, коли картку не видно.
`HClicker.soundState()` — стан для перевірки.

Назви `api.sfx(name, opts)`: `clay` (шльоп, `opts.hot`), `tap`, `soft`, `done`, `catch`, `rare`, `grab`, `coins`,
`buy`, `break`, `crackle`, `kiln`, `prestige`, `away`, `swish`, `fail`, `pop`. Синоніми: click/ui/tab/open/select →
tap; spin/slap/form → clay; ware/formed/ready/ok/success → done; ring/bell/golden/gift/guest/album/unlock → catch;
ringing/perfect/rank/wagon/achievement/q3 → rare; crack/broken/shatter → break; miss/wrong/lose → fail;
fire/stoke/light/roar/firing → kiln; wood/heat → crackle; coin/sell/bazaar/trade/market/pay/order/paid → coins;
paint/brush/trace → swish; drop → pop. Невідома назва — тихе «тук». `opts.x/y` (відсотки сцени) — центр спалаху.

Ядро кличе: `clay` на кожен зарахований клік, `break` на розбитий глек, `coins` на поверненого купця, `tap` на
вкладку; через `order()`: buy/mark/paint/tool/adorn/knead/secret → `buy`, sell/take/bazaar → `coins`, wear/form →
`tap`, catch → `catch`, grab → `grab`, fire → `prestige`. Ремесло — `done`.

## Права панель

- Рядок верстата: значок (рівень — плашкою на ньому), назва, опис з «×2», ціна й дрібно «окуп. …» (★ —
  найвигідніше), смужка «скільки ціни вже є» (крок 2 %, у `paint`). Віхи — такі ж компактні рядки.
- Банер «Наступна ціль» над вкладками: повна сушарня → віха по кишені (найдешевша) → верстат по кишені з
  найкоротшою окупністю → найближче за часом (верстат, віха, новий виріб). Клік — відкриває вкладку й підсвічує
  рядок. Інші частини додають свої цілі: `HClicker.goals.push((st, v, api) => ({ icon, text, sub, pct, eta, tab, prio }) | null)`
  (`icon` — вміст SVG 32×32, `prio`: 0 затор, 1 можна зараз, 2 найближче, 3 далі).
- Вкладки — один рядок із прокруткою, активна докручується в поле зору.
- «Хата»: знаряддя й прикраси з мальованими значками (`api.toolIcon`, `api.decorIcon`).

## «Поки тебе не було»

`view.away` показується раз на запис (`clk.awayAt` = `away.at`) карткою через `api.overlay`: скільки не було,
«+N глеків», скільки виліпили підмайстри, рядки `notes`. Відкрита чужа панель — чекаємо, поки закриють.
